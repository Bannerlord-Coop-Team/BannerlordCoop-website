# Subscription hold notice and save rescue

Deploy this website change before the paired ControlPlane change: the server-summary reader enforces exact keys. Older ControlPlanes may omit subscriptionHold; updated readers accept absence or null and validate the complete new object.

The notice shows a UTC removal date and explicitly warns that removal is permanent. Restore qualifying funding and the linked Patreon account before removal begins. While the ControlPlane grants canExportSave, the current owner can use Save & config -> Export save -> Download save export. This permission does not enable imports, restoration, Start, or provisioning. Existing backup history remains readable; there is no existing owner backup-download endpoint or undelete flow.

The warning is a persistent page notice derived from current subscription state, so it also covers existing grace periods and disappears when the hold is cleared. It is not a customer message or a dismissible announcement.

Deploying the website alone makes old suspended wording neutral; the dated notice and rescue button require the paired ControlPlane field and authorization change.
